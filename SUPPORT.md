## Getting Help

There are several ways to get help with PTO Tile Library:

### 📚 Documentation

- **[Getting Started Guide](docs/getting-started.md)** - Setup instructions for CPU simulation and NPU
- **[PTO ISA Manual](docs/PTO-Virtual-ISA-Manual.md)** - Complete ISA reference
- **[Programming Guide](docs/coding/ProgrammingModel.md)** - Core programming concepts
- **[API Reference](include/README.md)** - C++ header files and APIs

### 💬 Community

- **[GitHub Issues](https://gitcode.com/cann/pto-isa/issues)** - Report bugs and request features
- **[GitCode Discussions](https://gitcode.com/cann/community)** - Ask questions and share knowledge
- **[Community Forum](https://gitcode.com/cann/community)** - Connect with other developers

### 🐛 Reporting Bugs

When reporting bugs, please include:

1. **Environment details**:
   - Hardware (Ascend A2/A3/A5 or CPU)
   - CANN version
   - Operating system
   - Python version (if applicable)

2. **Steps to reproduce**:
   - Clear, numbered steps
   - Minimal code example if possible

3. **Expected vs actual behavior**

4. **Error logs** (if applicable)

### 💡 Feature Requests

For feature requests:

1. **Describe the feature** - What would you like to add?
2. **Use case** - Why do you need this feature?
3. **Alternatives** - Have you considered other approaches?

### 🤝 Contributing

See our [Contributing Guide](CONTRIBUTING.md) for information on how to contribute to PTO Tile Library.
